# Baseline Cell Segmentation Pipeline

The goal of this stage of the project is to establish a baseline for cell segmentation on the TRAgen time-lapse microscopy dataset. The baseline will later be compared against the first-frame initialization and cell-tracking approach.

The pipeline consists of three main stages:

1. Cell segmentation (`pipeline.py`)
2. Quantitative evaluation (`evaluate.py`)
3. Visualization (`visualize.py`)

## 1. Segmentation - `pipeline.py`

### What it does

Runs Cellpose on all 83 frames and saves the predicted segmentation masks.

### Dataset

* 83 grayscale microscopy frames generated by TRAgen:
  `img00000.tif` ... `img00082.tif`
* Ground-truth segmentation masks:
  `mask00000.tif` ... `mask00082.tif`

### How it works

#### Loading frames

```python
image_files = sorted(
    glob.glob(os.path.join(DATA_DIR, "img?????.tif"))
)
```

`glob` finds all matching TIFF files, while `sorted()` ensures chronological order.

#### Loading the first ground-truth mask

```python
first_mask = tifffile.imread(first_mask_path)
```

The first mask is loaded to determine how many cells are present at the start of the sequence:

```python
len(np.unique(first_mask)) - 1
```

The `-1` excludes the background.

#### Image normalization

```python
image = (image - image.min()) / (
    image.max() - image.min() + 1e-8
)
```

Each frame is normalized to the `[0, 1]` range.

The small value `1e-8` prevents division by zero.

#### Running Cellpose

```python
model = models.CellposeModel(
    gpu=True,
    pretrained_mode="cyto3"
)

mask, flows, styles = model.eval(
    image,
    diameter=None,
    channels=[0, 0]
)
```

* `cyto3` is a pretrained Cellpose model for cytoplasm segmentation.
* `diameter=None` allows Cellpose to estimate the cell size automatically.
* `channels=[0, 0]` specifies a grayscale input.

#### Saving output

Each predicted mask is saved as a 16-bit TIFF file:

```text
output_masks/pred_mask00000.tif
output_masks/pred_mask00001.tif
...
output_masks/pred_mask00082.tif
```

## 2. Evaluation - `evaluate.py`

### What it does

Compares predicted masks against the TRAgen ground-truth masks and calculates segmentation metrics for each frame.

### Metrics

#### IoU (Intersection over Union)

Measures the overlap between predicted and ground-truth cell regions.

$$
IoU = \frac{intersection}{union}
$$

A value of `1.0` means perfect overlap.

The current baseline achieves approximately **0.852 mean IoU**.

#### Dice Score

Measures the overlap between predicted and ground-truth regions.

$$
Dice = \frac{2 \times intersection}
{GT\ pixels + predicted\ pixels}
$$

The current baseline achieves approximately **0.920 mean Dice score**.

#### Precision

Measures how many pixels predicted as cells are actually cell pixels.

$$
Precision = \frac{intersection}{predicted\ pixels}
$$

#### Recall

Measures how many actual cell pixels were correctly predicted.

$$
Recall = \frac{intersection}{GT\ pixels}
$$

#### F1 Score

The harmonic mean of precision and recall.

$$
F1 =
\frac{2 \times Precision \times Recall}
{Precision + Recall}
$$

#### Cell Count Error

The absolute difference between the number of cells in the ground truth and prediction.

$$
Cell\ Count\ Error =
|GT\ Cell\ Count - Predicted\ Cell\ Count|
$$

### Output

Results are saved to:

```text
results.csv
```

The file contains one row per frame with the calculated metrics.

## 3. Visualization - `visualize.py`

### What it does

Generates side-by-side comparison images for selected frames showing:

* Original microscopy image
* Ground-truth mask overlaid on the image
* Predicted mask overlaid on the image

### Frames visualized

The following frames are selected:

```text
0, 10, 40, 60, 82
```

These represent different stages of the time-lapse sequence.

### How the overlay works

The original image is displayed in grayscale:

```python
axes[1].imshow(img, cmap="gray")
```

The segmentation mask is then displayed on top with 50% transparency:

```python
axes[1].imshow(
    gt,
    cmap="nipy_spectral",
    alpha=0.5
)
```

The `alpha=0.5` setting makes the original microscopy image visible underneath the mask.

Each cell receives a different color from the colormap.

## Baseline Purpose

This implementation serves as the baseline segmentation system for the project.

Currently, each frame is processed independently by Cellpose. No first-frame information is used to guide later frames, and cells are not assigned persistent identities across frames.

The baseline will later be compared with a first-frame initialization and cell-tracking approach.
